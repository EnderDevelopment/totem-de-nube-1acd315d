# Cloud Totem Plugin

The Cloud Totem Plugin is a Minecraft plugin that adds a new totem called "Totem de Nube" to the game. When used, this totem grants the player levitation for 3 seconds and prevents fall damage. This plugin is designed for Minecraft Bedrock Edition version 26.50 and above.

## Install

1. Download the plugin file from the GitHub repository.
2. Place the plugin file in the `plugins` folder of your Minecraft server.
3. Restart the server to load the plugin.

## Use

1. Use the command `/givecloudtotem` to give yourself a Cloud Totem.
2. Right-click with the Cloud Totem to activate its effects.
